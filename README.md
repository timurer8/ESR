1. ПАСПОРТ И ПРЕДЫСТОРИЯ ПРОЕКТА
EdgeStream Reader (ESR) — это портативное, отказоустойчивое приложение
для чтения электронных книг и документов с интегрированной функцией
асинхронного потокового синтеза речи (TTS). Программа разработана как
эффективная альтернатива громоздким аналогам, сочетая минималистичный
GUI на базе CustomTkinter и продвинутые алгоритмы предобработки текста.

2. АРХИТЕКТУРА И СТРУКТУРА КОДА (5 БАЗОВЫХ БЛОКОВ)
Код приложения жестко структурирован и разделен на изолированные зоны:
• БЛОК 1: Главный GUI и инициализация среды. Отвечает за верстку окон,
адаптивные виджеты, привязку контекстного меню и защищенную загрузку
логотипа приложения из файла icon.ico для главного и дочерних окон.
• БЛОК 1.2: Менеджер вкладок настроек. Управляет переключением светлой/
тёмной темы, пресетами фонов подложки («Книжная Сепия», «Ночной OLED»)
и выводит справочные данные релиза с интерактивными ссылками на README.
• БЛОК 1.3: Интерактивный модуль словаря ударений и закладок. Реализует 
логику дочерних Toplevel-окон, обработку кликов по элементам и вывод 
сохраненных позиций на лету по глобальным индексам чанков из JSON.
• БЛОК 2: Всеядный парсер и нормализатор текста. Содержит движки импорта
книг, ювелирный алгоритм очистки «Убийца Notepad++», таблицы замен Е/Ё
и математический модуль склонения физических величин.
• БЛОК 3: Потоковый стриминг-плеер и асинхронный префетчер ОЗУ. Управляет
фоновым кэшированием аудио напрямую в память через io.BytesIO без записи 
на диск, последовательным запуском чанков и сквозной трансляцией цвета 
в независимое окно чтения (ESRReaderWindow).
• БЛОК 4: Энергосберегающая «Умная Пауза» и экспорт. Фиксирует точное
место чтения, управляет триггерами кнопок, очисткой кэша памяти при стопе
и монолитным склеиванием MP3-файлов при экспорте.
• БЛОК 5: Логика сериализации JSON состояния. Обеспечивает сохранение
и холодное восстановление параметров (путь, индекс, тема, фон, темп).

3. КЛЮЧЕВЫЕ ФУНКЦИИ ВЕРСИИ v1.8.5-beta
• Всеядность форматов: Прямой импорт текстовых файлов (.txt), 
электронных книг (.fb2, .epub) и документов Microsoft Word (.docx).
• Алгоритм «Убийца Notepad++»: Интеллектуальный парсинг строк, 
удаляющий мусор сканирования (OCR), множественные пробелы, табы,
хвосты многоточий и одинокие скобки, ломающие интонацию диктора.
• Интеллектуальный модуль склонений: Автоматическая расшифровка и
склонение годов (г., гг.), городов (г. Москва -> город Москва) и
физических величин (кг, км, м, руб) с автоматическим подбором
правильных окончаний в зависимости от числительного перед ними.
• Инновационное RAM-кэширование (Diskless): Полный отказ от временных 
файлов на HDD/SSD. Аудио генерируется в оперативную память через BytesIO, 
что полностью исключает износ накопителей и убирает тактовые фризы.
• Асинхронный префетчер ОЗУ: Умный фоновый предзаказ (глубина: 4 чанка 
вперед) гарантирует бесшовное чтение и воспроизведение без пауз.
• Синхронное окно суфлёра: Дочерний экран чтения (ESRReaderWindow) на лету 
подчиняется цветовым схемам главного ядра и сохраняет иконку icon.ico.
• Исправленная база закладок: Полная защита от KeyErorr при открытии новых 
книг, корректный вывод в поле bm_display и удаление по индексу чанка.
• Контекстная замена Е/Ё: Автоматическая правка критичных омографов
(все -> всё, еще -> ещё) для обеспечения идеального произношения.
• Локальный словарь ударений: Файл esr_user_dict.json позволяет вручную
задавать жесткие правила чтения редких слов и имен символ-в-символ
с сохранением регистра заглавных букв на стыках предложений.

3.1. СПЕЦИФИКАЦИЯ ФУНКЦИИ «СОХРАНИТЬ АУДИО» И ФОРМАТЫ ЭКСПОРТА
Программа поддерживает продвинутый высокоскоростной экспорт текста в аудиофайлы:
• Онлайн-движок (Edge-TTS) — осуществляет пакетное сканирование, склеивание
  потоков в ОЗУ и сохраняет итоговое аудио исключительно в формате MP3.
• Офлайн-движок (SAPI5) — выполняет поабзацный рендеринг через системные
  кодеки Windows и сохраняет итоговый файл в несжатом формате WAV.

Сохранение аудиофайла возможно выполнить четырьмя гибкими способами:
1. Полный экспорт — конвертирует весь текст от самого начала до конца 
   (работает в фоне, без запуска фактического воспроизведения в плеере).
2. Экспорт от паузы — преобразует текст, начиная строго с момента текущей 
   активной паузы плеера и до самого конца документа.
3. Экспорт от маркера — конвертирует текст от вручную установленной позиции 
   и до конца книги.
4. Экспорт выделения — генерирует аудиофайл строго для фрагмента текста, 
   который пользователь выделил мышью на экране.

🔥 ВАЖНО: Установка маркера чтения для третьего способа экспорта осуществляется
в один клик — нажмите ЛЕВОЙ КЛАВИШЕЙ МЫШКИ (ЛКМ) на любой абзац текста 
в основном окне программы, чтобы мгновенно зафиксировать там маркер!

4. ГОРЯЧИЕ КЛАВИШИ И УПРАВЛЕНИЕ ПЛЕЕРОМ
• Кнопка «► Озвучить» — Запуск воспроизведения с текущего абзаца.
• Кнопка « ⏸ Пауза / ► Продолжить» — Временная остановка с фиксацией
закладки. При холодном перезапуске кнопка адаптируется в зеленый режим
готовности к возобновлению чтения.
• Кнопка « ⬛ Стоп» — Сброс прогресса, очистка кэша ОЗУ и сброс книги
с сохранением общих графических настроек и темпа.
• Клик по строке в словаре/закладках — Выбор позиции для перехода или удаления.
• ⚠ Внимание: При изменении скорости темпа ползунком во время чтения, новый темп
вступит в силу через 3-4 чанка (в связи с работой упреждающего кэширования ОЗУ).

5. СИСТЕМНЫЕ ТРЕБОВАНИЯ И ЗАВИСИМОСТИ
Для успешного запуска переносной версии из исходного кода необходимы:
• Интерпретатор Python 3.14+
• Библиотеки: customtkinter, edge-tts, pygame-ce, beautifulsoup4, 
lxml, ebooklib, python-docx.
• Доступ в сеть интернет (для работы облачного API Microsoft Speech).
• Спецификация для офлайн-синтеза (SAPI5):
    - Для озвучки и сохранения при помощи офлайн-движка в операционной системе 
      должны быть установлены офлайн-голоса "SAPI 5 TTS" Dariya, Dmitry, 
      Svetlana, Ekaterina.
    - Для использования современных высококачественных голосов Microsoft Native 
      необходимо установить утилиту NaturalVoiceSAPIAdapter:
      * Скачайте и распакуйте архив в отдельную папку (эту папку нельзя удалять 
        или перемещать, пока голоса используются в системе).
      * Запустите файл Installer.exe, активируйте необходимые вам настройки, 
        после чего нажмите кнопки "Install 32-bit" и "Install 64-bit".
